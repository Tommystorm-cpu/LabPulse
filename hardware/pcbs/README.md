# Sensor-hub PCB revisions

These archives contain board-manufacturing artwork (Gerber files) and drill
files for sensor-hub prototypes. The index identifies the files available for
inspection and adaptation.

## Revision index

| Archive | Recorded label | Contents inspected |
|---|---|---|
| [Prototype 1](Gerber_PCB_Arduino-Hat_prototype1.zip) | Arduino-Hat prototype1 | Copper, silkscreen, solder masks, board outline, drill files and ordering notes |
| [Prototype 2](Gerber_PCB_Arduino-Hat_prototype2_2025-11-14.zip) | Arduino-Hat prototype2; filename dated 2025-11-14 | Copper, silkscreen, solder masks, board outline, drill files, document layer and ordering notes |
| [Prototype 3](Gerber_PCB_Arduino-Hat_prototype3.zip) | Arduino-Hat prototype3 | Copper, silkscreen, solder masks, board outline, drill files, document layer and ordering notes |
| [Final prototype](Gerber_PCB_Arduino-Hat_Final_prototype.zip) | Arduino-Hat Final_prototype | Copper, silkscreen, solder masks, board outline, drill files, document layer and ordering notes |
| [PCBv6](PCBv6.zip) | PCBv6 | Copper, silkscreen, solder masks, solder paste, profile, drill and Gerber job files |

Before choosing a revision for manufacture, match its markings and connections
to your hardware, check the sensor and firmware pin assignments, and verify
the electrical design. Keep the editable schematic and board-layout source
with any new revision you contribute.

See [Hardware](../../docs/HARDWARE.md#existing-hardware-assets) for
sensor parts and wiring guidance.
